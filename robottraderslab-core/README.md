# RobotTradersLab Core

The base package of the RobotTradersLab trading surface, imported as `robottraderslab_core`.

> **Beta.** RobotTradersLab is under active development. Until version 1.0, a minor release (0.x) can include breaking changes and a patch release (0.x.y) never does. Every change is listed in the [release notes](https://github.com/RobotTraders/RobotTradersLab/releases). We recommend running your bot on a demo account before you trade real money.

## Documentation

The documentation of RobotTradersLab is at [robottraders.io/lab/docs](https://robottraders.io/lab/docs), and the [API reference](https://robottraders.io/lab/docs/reference.html) lists the names this package holds.
